Superstore Sales Performance Dashboard

Project Overview
This project is part of the AnalystLab Africa Data Analytics Internship Programme (Week 3). The objective is to perform advanced data analysis, develop meaningful Key Performance Indicators (KPIs), and create an interactive Business Intelligence Dashboard for a retail superstore using Sample Superstore Dataset (2014-2016)

Tools Used
Power BI: Interactive Dashboard Creation
DAX: Calculated Measures & Time Intelligence
Power Query: Data Transformation & Preparation
Excel: Supporting Analysis
GitHub: Version Control & Documentation

Key Performance Indicators (KPIs)
Total Sales: $2.30M
Total Profit: $286.40K
Profit Margin: 12.47%
Order Volume: 4,832 Orders
Avg. Discount: 15.62%
Products Making Loss: 2,000+ Line Items

Key Business Insights
Profitability Drivers: Office Supplies delivers better profit margins than Technology despite lower sales volume.
Loss-Making Products: Tables sub-category is the primary loss driver, generating ~$33,600 in losses.
Regional Performance: West region leads profit ($108K), while Central region underperforms ($39.7K).
Discount Impact: High discounts correlate with lower profitability, especially in Furniture category.
Customer Concentration: Consumer segment drives 52% of revenue, creating business risk.
Seasonal Trends: Q4 shows significant sales spikes; Q1 consistently underperforms.
